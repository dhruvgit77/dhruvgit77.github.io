Second Brain

A personal, local-first knowledge assistant.

What it does

Second Brain is a single-user personal productivity tool. It runs entirely on its owner's own computer and helps them keep track of their own email, calendar, tasks, and files by organising that information into a local folder of Markdown notes that they can read and edit themselves.

How it uses Google services

  • Gmail (read-only) — reads the user's own messages to identify which ones may need a reply, and to summarise what arrived while they were away.
  • Gmail (compose) — saves draft replies to the user's own Gmail drafts folder for them to review. The application cannot send email: the gmail.send permission is deliberately not requested.
  • Google Calendar (read-only) — reads upcoming events so the user can be reminded about them.
  • Google Tasks (read-only) — reads task due dates to surface approaching and overdue deadlines.
  • Google Drive (metadata only) — reads file names and modification times to show recently changed documents. File contents are never accessed.

Where the data goes

Nowhere. All processing happens on the user's own machine. There is no server, no database, no analytics, and no third party. The application is used by one person: its author.

Source

Second Brain is a personal project built with the Claude Agent SDK, Python, and SQLite. It is not a commercial product and is not offered to other users.
