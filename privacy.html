Privacy Policy

Second Brain — last updated 21 August 2026

Summary

Second Brain is a single-user application that runs on its owner's personal computer. It accesses only that person's own Google account, with their explicit consent, and stores everything locally. No data is transmitted to the developer or to any third party, because there is no server to transmit it to.

What is accessed

gmail.readonlyMessage headers and snippets, to identify mail that may need a reply.
gmail.composeCreating draft replies for the user to review. Sending is not possible.
calendar.readonlyUpcoming event titles and times, for reminders.
tasks.readonlyTask titles and due dates, to surface deadlines.
drive.metadata.readonlyFile names and modification times only. File contents are never read.

How it is stored

Summaries and notes are written to Markdown files in a folder on the user's own computer. OAuth tokens are stored locally with restricted file permissions and are excluded from version control. Nothing is uploaded anywhere.

How it is shared

It is not. There is no analytics, no telemetry, no advertising, and no sale or transfer of data. The application has exactly one user, who is also its developer.

Language models

The application uses Anthropic's Claude models to summarise the user's own content and to draft replies for their review. Content sent to that API is governed by Anthropic's privacy policy. Credentials and access tokens are never included in those requests: they are held by local Python code and never placed into a model prompt.

Retention and deletion

All data lives in local files under the user's control and can be deleted by deleting those files. Access can be revoked at any time from Google Account permissions, which immediately and permanently ends the application's access.

Limited Use disclosure

Second Brain's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
